Current Model Demo

Road Damage Demo: Supported Classes

The platform is intended to support automated dataset labeling across use cases. The currently available demo model is trained to detect these four road-damage categories:

D00 Longitudinal Cracks

D00 / Longitudinal Cracks

Cracks running along the wheel mark or construction joints.

D10 Transverse Cracks

D10 / Transverse Cracks

Lateral/perpendicular cracks across the lane or joints.

D20 Alligator Cracks

D20 / Alligator Cracks

Interconnected fatigue-related network cracks.

D40 Potholes

D40 / Potholes

Visible holes or cavities in the road surface.

Demo Scope & Human Review: This is a road-damage demo, not a general-purpose model for every dataset or label type. The D40 class represents potholes and does not independently detect ruts or bumps. Automated predictions can contain errors, so human inspection and correction are important before labels are used for model training.

Automated Labeling Workflow

How Annotation Wizard Works

From image datasets to machine-generated annotations, with human inspection as an important quality-control step.

1

Upload Image Dataset

For the current demo, upload a ZIP archive of images (JPG, PNG, or WebP). Archive safety limits apply: up to 50 MB and 100 images.

2

Automatic Labeling

The currently available road-damage model runs on CPU through ONNX Runtime and predicts objects in each image. Other model types are not available in this demo yet.

3

Generate Annotations

For this object-detection demo, predictions are exported as normalized YOLO bounding boxes in per-image .txt files, alongside the required class and dataset metadata.

4

Download and Inspect Labels

Download a lightweight ZIP containing the generated label files and supporting metadata. Inspect and correct the annotations before using them in a training pipeline; an interactive review-and-editing workspace is a planned part of the broader platform.
